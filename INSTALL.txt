Clickable Scrollbars - v2.15

Mouse accessibility for Helldivers 2 menu scrollbars.

Release for Steam build 25480438 / EXE 1.8.46015.0. Offline checks passed;
scrollbar dragging works in live play.

INSTALL
1. Close Helldivers 2.
2. Import Clickable-Scrollbars-v2.15.zip into Arsenal or HD2MM, replacing the
   previous standalone Clickable Scrollbars entry.
3. Enable it together with Bingus Shared Loader v18 or newer.
4. With Arsenal's default priority, place the shared loader last, then
   Purge / Deploy. Use one manager; do not copy patch files into the game folder.
5. If an old diagnostic INI contains native=0, remove that line or set native=1.
   INI: %LOCALAPPDATA%\ClickableScrollbars\ClickableScrollbars.ini

Do not enable a second copy of the addon (including a megapack copy) alongside
this package.

USING IT
Grab the thumb to drag, or click the track to centre it there. A thumb click
without movement leaves the list in place. Equipment and Career follow vertical
pointer movement regardless of horizontal position after the thumb is grabbed.
Both clamp at the track ends and use native scrolling without wheel input.
Display settings drags consume the held selection so options and tabs do not
activate under the pointer. Release, then click normally to activate a control.

Unsupported or hidden menus are left alone, with no screenshot or wheel fallback.
Focus loss or a changed native list cancels a hold. Release and grab again to
start a new one. Ordinary gameplay clicks do not capture pixels or write routine
logs.

VALIDATION
Offline checks cover the Armory, Career and Display settings scrollbars, the
Windows API bindings and the package. Scrollbar dragging works in live play;
the mission loadout scrollbar and the Display settings fix have not been
confirmed separately in game.
Supported build: Steam 25480438 / EXE 1.8.46015.0.

Log: %LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ClickableScrollbars.log
Set diagnostics=1 in the optional INI only when collecting native_writes,
native_ok, errors and gesture traces.

The addon is plaintext Lua. Native scrolling writes UI data and invokes the
existing layout solver; it installs no system hooks or executable patches.

UNINSTALL
Disable the mod, purge the deployment and redeploy the remaining mods. Restart
the game to remove the addon from the running session.

Requires Bingus Shared Loader v18 or newer / API 1, installed separately:
https://github.com/CowboyBingus/BingusSharedLoader/releases/latest
