Clickable Scrollbars - v2.6

Mouse accessibility for Helldivers 2 menu scrollbars.
Requires Bingus Shared Loader v15 or newer / API 1, installed separately.

INSTALL
1. Close Helldivers 2.
2. Import Clickable-Scrollbars-v2.6.zip into Arsenal or HD2MM, replacing the
   previous standalone Clickable Scrollbars entry.
3. Enable it together with Bingus Shared Loader v15 or newer.
4. With Arsenal's default priority, place the shared loader last, then
   Purge / Deploy. Use one manager; do not copy patch files into the game folder.
5. If an old diagnostic INI contains native=0, remove that line or set native=1.
   INI: %LOCALAPPDATA%\ClickableScrollbars\ClickableScrollbars.ini

Do not enable a second copy of the addon (including a megapack copy) alongside
this package. The separate VanillaPlusMegapack snapshot is not updated here.

USING IT
Grab the thumb to drag, or click the track to centre it there. A thumb click
without movement leaves the list in place. Equipment and Career follow vertical
pointer movement regardless of horizontal position after the thumb is grabbed.
Both clamp at the track ends and use native scrolling without wheel input.

Other detected bars use wheel input and pause when the pointer leaves the
scrollbar. That fallback has the game's wheel-step granularity. Focus loss or
a changed native list cancels a hold. Release and grab again to start a new one.

VALIDATION
Offline tests pass, and v2.6 has been verified in-game.
Windows API bindings and the interactive desktop-capture check pass.
Supported build: Steam 24826606 / EXE 1.8.45317.0.

Log: %LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ClickableScrollbars.log
Check the v2.6 header, native_writes, native_ok, native_fallbacks, errors and trace.
Test slow drags, fast drags, both ends, returning from an end, crossing the tabs,
release over a tab, and a fresh normal tab click after release.

The addon is plaintext Lua. Native scrolling writes UI data and invokes the
existing layout solver; it installs no system hooks or executable patches.

UNINSTALL
Disable the mod, purge the deployment and redeploy the remaining mods. Restart
the game to remove the addon from the running session.
